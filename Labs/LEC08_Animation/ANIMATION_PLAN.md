# 스프라이트 애니메이션 제작 계획

## 목표

`pico2d`와 `AI_Sprite.png` 스프라이트 시트를 사용해 4종류의 애니메이션을 순서대로 재생한다. 제작은 작은 단계로 나누어 진행하며, 각 단계의 검증 결과를 별도 커밋으로 기록한다.

## 확정 요구사항

- 애니메이션 종류는 총 4개이며, 각 종류마다 프레임 크기와 프레임 수가 다르다.
- 애니메이션은 화면 중앙에 표시한다.
- 캐릭터의 표시 크기는 화면의 절반 이상이어야 한다. 비율을 유지하면서 렌더링하고, 최소 크기는 화면 높이의 절반 이상이 되도록 맞춘다.
- 각 애니메이션을 처음부터 끝까지 5회 재생한 뒤 1초간 정지한다.
- 네 애니메이션을 정해진 순서대로 재생하고, 네 번째 애니메이션 뒤에는 첫 번째로 돌아가 무한 반복한다.
- 구현은 한 번에 완성하지 않고 작은 검증 가능한 단계로 진행한다.
- 구현 과정에서 최소 21개의 의미 있는 커밋을 만든다. 계획 문서 추가는 구현 커밋 수에 포함하지 않는다.

## 아직 확인할 값

실제 스프라이트 시트의 프레임 배치를 확인한 뒤 아래 값을 확정한다. 임의의 프레임 크기나 개수를 미리 가정하지 않는다.

현재 확인된 자산은 `AI_Sprite.png`이며 크기는 1792 x 2358 픽셀, 형식은 RGBA PNG다. 파일명과 작업 폴더 외에 제작자, 원본 출처, 사용권 정보는 확인되지 않았다. 배포 전에 출처와 사용 허가를 별도로 확인한다.

| 순서 | 애니메이션 | 프레임 너비 | 프레임 높이 | 프레임 수 | 시트/영역 |
|---|---|---:|---:|---:|---|
| 1 | 애니메이션 A | 미정 | 미정 | 미정 | 미정 |
| 2 | 애니메이션 B | 미정 | 미정 | 미정 | 미정 |
| 3 | 애니메이션 C | 미정 | 미정 | 미정 | 미정 |

추가 확인 항목: 시트 내 시작 좌표와 행/열 배치, 프레임 재생 속도, 화면 크기, 4종류의 실제 재생 순서. 프레임별 간격이 불규칙하면 단순한 균등 격자 추출 대신 프레임 좌표를 개별 지정한다.

## 재생 규칙

- 각 애니메이션은 해당 프레임 목록을 순서대로 재생한다.
- 한 번의 반복은 애니메이션의 모든 프레임을 한 차례 표시하는 것으로 센다.
- 같은 애니메이션을 5회 완료한 뒤 1초 타이머를 진행한다. 정지 중에는 다음 애니메이션 프레임을 표시하지 않는다.
- 정지가 끝나면 다음 애니메이션으로 이동한다. 마지막 애니메이션의 정지까지 끝나면 첫 번째 애니메이션으로 돌아간다.
- 프레임 속도와 타이머는 실제 경과 시간 기준으로 갱신해 실행 환경의 프레임률에 좌우되지 않도록 한다.
- 캐릭터의 중심 좌표는 화면 중앙에 고정한다. 크기 조정 시 원본 종횡비를 보존하고 모든 애니메이션에서 일관된 표시 크기를 유지한다.

## 단계별 커밋 계획

각 단계는 동작 가능한 상태를 유지하고, 해당 단계의 간단한 실행 또는 동작 확인 후 커밋한다. 제목은 작업 중 코드베이스의 커밋 규칙에 맞게 조정할 수 있지만, 서로 다른 변경을 한 커밋에 합치지 않는다.

| # | 커밋 내용 |
|---:|---|
| 1 | 애니메이션 실행 파일의 기본 창 열기/닫기 구조 작성 |
| 2 | 화면 크기와 중앙 좌표를 한곳에서 관리 |
| 3 | `AI_Sprite.png` 추가 및 확인된 파일 정보와 출처 상태 기록 |
| 4 | 스프라이트 시트 크기와 프레임 배치 조사 |
| 5 | 애니메이션 4종의 프레임 메타데이터 정의 |
| 6 | 시트에서 단일 프레임을 지정해 그리는 기능 구현 |
| 7 | 프레임 영역 계산을 별도 함수로 분리하고 검증 |
| 8 | 한 종류의 프레임을 순서대로 재생 |
| 9 | 시간 기반 프레임 갱신 적용 |
| 10 | 표시 위치를 화면 중앙으로 고정 |
| 11 | 종횡비를 보존하는 확대/축소 적용 |
| 12 | 화면 절반 이상 크기 조건 확인 및 크기 조정 |
| 13 | 애니메이션별 반복 횟수 상태 추가 |
| 14 | 한 애니메이션을 정확히 5회 재생하도록 구현 |
| 15 | 5회 완료 후 1초 정지 상태 추가 |
| 16 | 네 애니메이션을 지정된 순서로 전환 |
| 17 | 마지막 애니메이션 뒤 첫 번째로 순환 |
| 18 | 전체 재생 흐름을 상태 전이로 정리하고 경계 조건 처리 |
| 19 | 모든 애니메이션의 프레임/반복/정지 동작 점검 |
| 20 | 창 닫기와 시간 갱신 등 실행 중 예외 상황 점검 |
| 21 | 최종 수동 검증, 불필요한 임시 코드 정리, 완성 커밋 |

## 완료 기준

- 네 종류가 각각 올바른 프레임 크기와 프레임 수로 표시된다.
- 캐릭터 중심이 화면 중앙에 유지되고 표시 높이가 화면 높이의 절반 이상이다.
- 각 애니메이션이 5회 재생 후 1초 정지하며 지정 순서대로 이어진다.
- 네 번째 애니메이션이 끝난 뒤에도 중단 없이 첫 번째로 돌아간다.
- 위 동작을 실제 실행으로 확인하고, 구현 변경을 최소 21개의 커밋으로 나누어 기록한다.
